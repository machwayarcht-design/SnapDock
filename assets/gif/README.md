# Demo GIF

`demo.gif` 无法由脚本自动生成，因为它需要**真机运行 SnapDock** 才能录制真实的交互效果。请在本地安装并启动 SnapDock 后，按下方流程录制。

## 录制建议

- **工具**：[LICEcap](https://www.cockos.com/licecap/) 或 [ScreenToGif](https://www.screentogif.com/)（均免费）
- **时长**：约 30 秒
- **画面**：保持窗口简洁，建议录制 1280×720 或更小区域

## 推荐录制流程

1. 按 `Ctrl + ~` 打开布局面板
2. 按 `1` 应用「单窗口」布局
3. 按 `2` 切换到「左右双分」布局
4. 调整好窗口后，按 `Ctrl + Shift + 1` 保存当前布局
5. 按 `Ctrl + 1` 恢复已保存的布局

## 导出与放置

将录制的动画导出为 `demo.gif`，并放入本目录（`assets/gif/`）。
README 已通过以下语句引用：

```markdown
![demo](assets/gif/demo.gif)
```

> 若尚未录制，可暂时使用本目录下的 `placeholder.png` 作为占位图。

## 视频替代方案

除了 GIF，你也可以将演示视频上传至 **YouTube** 或 **Bilibili**，
然后在 README 中嵌入视频链接（如 YouTube 的 `<iframe>` 或 Bilibili 的 `//player.bilibili.com` 嵌入代码）。
